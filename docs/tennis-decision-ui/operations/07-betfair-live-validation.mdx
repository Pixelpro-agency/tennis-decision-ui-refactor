# Validazione live Betfair — Task 2

**Stato:** Completata con rilievi documentati — 2026-07-04

## Scopo

Questo documento registra la validazione manuale reale della pipeline Task 2:

```txt
Sofa
→ Source Identity
→ Betfair
→ timeline
→ latest
→ read model
→ Volume abbinato nel tempo
```

Non è una nuova specifica funzionale. I contratti tecnici appartengono alla documentazione Task 2A–2E già esistente.

## Sessione A — Graph URL disponibili

```txt
Sofa: Connected

Source Identity:
→ phase recording
→ persistence canonical
→ status aligned

Betfair health green
graphHealth ok

2 Graph URL fornite
→ 2 tentate
→ 2 riuscite
→ 0 fallite

ladderSource graph_url per entrambi i runner
selectionId stabile
seq osservata: 29 → 30 → 31
matchedVolume positivo osservato
grafico Volume abbinato nel tempo visibile e coerente
```

Non vengono riportati nomi dei giocatori o URL Graph completi.

## Sessione B — senza Graph URL

```txt
Sofa: Connected
tracking ancora attivo
graphHealth unavailable
reason no_graph_urls_provided

Betfair yellow / STALE
→ non red
→ non technical error

ladderSource book_depth
matchedVolume positivo possibile con delta coerenti
nessun stop inatteso
nessuna duplicazione o regressione seq osservata
```

Un tick ha prodotto:

```txt
market_delta_raw_computed_mismatch
→ matchedVolume 0
→ validForDisplay false
→ invalidVolume true
→ anomaly true
```

Questo conferma la soppressione protettiva del point, non un errore di tracking.

## Sessione C — logout Graph e recovery

```txt
sessione live stabile
→ logout Betfair manuale

logout Graph rilevato
→ tick status-only persistito
→ graphHealth auth_suspected
→ health red / ALERT
→ popup visuale e audio osservati

login Betfair ripristinato
→ ritorno a Connected osservato
```

Questa è un’osservazione live manuale. Non è archiviato un payload `/latest` post-fix e non esiste un test automatico PASS dedicato al tick `status-only`.

## Limiti

Le sessioni A e B hanno riutilizzato lo stesso `eventId`.

```txt
seq, timeline e scala grafico della seconda sessione
→ non completamente isolate
```

Non sono stati validati live:

```txt
login Betfair scaduto
URL Graph malformate
mismatch marketId
errore API/rete reale
mercato Betfair realmente finished
```

Il logout Graph esplicito e il recovery dopo login della Sessione C non equivalgono alla validazione di una sessione che inizi con login Betfair già scaduto.

La verifica seguente è osservata:

```txt
/json = 200
→ Sofa: Connected
```

Il caso:

```txt
404 timeline Sofa durante Source Identity buffering
→ Sofa: In attesa
```

è stato riferito come osservazione manuale risolta, ma non ha screenshot, payload o log allegati in questo report. Non viene presentato come evidenza archiviata.
